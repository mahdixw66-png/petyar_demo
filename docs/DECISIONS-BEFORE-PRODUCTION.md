# تصمیم‌های باز پیش از عرضهٔ واقعی

- [ ] برند و دامنه نهایی
- [ ] بیمه‌گر مجاز و مجوزهای قانونی
- [ ] تعرفه، سقف، فرانشیز، دوره انتظار، استثناها — مصوب و منتشرشده توسط نقش مجاز
- [ ] قواعد دقیق فرانشیز/سهم/سقف (انواع مختلف) و مدل محاسبه نهایی
- [ ] فرایند حقوقی، شرایط استفاده و حریم خصوصی — بازبینی وکیل
- [ ] درگاه پرداخت واقعی و حساب تسویه
- [ ] سرویس پیامک/ایمیل و الگوهای通知
- [ ] کلید نقشه، سیاست نگهداری فایل‌ها (S3 خصوصی + لینک کوتاه‌عمر)
- [ ] بکاپ، مانیتورینگ، لاگ متمرکز، سیاست rotate secret
- [ ] تصمیم ورود/عدم ورود نوبت‌دهی و ویزیت آنلاین به MVP
