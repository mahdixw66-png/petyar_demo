# قابلیت‌های غیرفعال یا شبیه‌سازی‌شده

| قابلیت | وضعیت در MVP | توضیح |
|---|---|---|
| پرداخت واقعی | ❌ غیرفعال | هیچ انتقال وجه انجام نمی‌شود |
| تسویه به کلینیک | ⚠️ شبیه‌سازی‌شده | فقط `SETTLED_SIMULATED`، با هشدار واضح «پرداخت واقعی نیست» |
| پیامک/ایمیل | ❌ غیرفعال | فقط Notification درون‌برنامه‌ای |
| نقشه زنده | ❌ غیرفعال | فهرست کلینیک‌ها نمونه، نقشه نیازمند کلید API |
| نوبت‌دهی آنلاین | ❌ غیرفعال | فقط نمونه UI با برچسب فاز بعد |
| ویزیت تصویری | ❌ غیرفعال | فقط نمونه UI |
| نرخ‌های مصوب | ❌ نمونه | تمام اعداد با برچسب «نمونهٔ آموزشی — پیشنهاد بیمه‌ای نیست» |
| صدور قانونی بیمه‌نامه | ❌ نمونه | بیمه‌نامه‌های seed تأییدنشده‌اند |
| وضعیت تأییدشده = پرداخت | ❌ هرگز | مستندسازی شده که تأیید ≠ پرداخت |

این موارد عمداً وانمود نمی‌شوند و در UI با هشدار نمایش داده شده‌اند.
